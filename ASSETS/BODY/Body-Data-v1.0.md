# Purpose

This document records observable body language, movement patterns, emotional patterns, and style expressions.

The objective is to create a structured reference for future body-related assets, narrative systems, media systems, and human-AI interaction models.

This document serves as the initial body asset of HSDD.

---

# Body Asset Overview

Body assets are composed of four domains:

- Pose
- Motion
- Emotion
- Style

Together they form an evolving body language system.

# Body Asset Framework

```text
Pose
    ↓
Motion
    ↓
Emotion
    ↓
Style
```

Changes in one layer may influence the others.

The framework is intended as an observation model rather than a rigid classification system.
